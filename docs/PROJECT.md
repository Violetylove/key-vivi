## 执行顺序

1. 完成输入状态测试：左右修饰键、单独释放、长按后组合、保持修饰键连续组合。
2. 完成 UI 调度及隐藏定时器回归，执行 v0.1 桌面验收。
3. 实现托盘、暂停与退出，验证无边框、置顶、点击穿透，验收 v0.5。
4. 完成极简视觉、动画、隐私与目标机器分发测试，验收 v1.0。
5. 确认 v2.0 范围后实施配置、可选风格、鼠标及多显示器。

## 风险与约束

- Fyne 桌面构建涉及 CGO/C 编译器；开发依赖与用户运行依赖分别验证。
- channel 不等于 UI 线程调度；后台协程更新 UI 需使用框架调度机制。
- Win32 钩子需有效消息循环；回调不得阻塞正常键盘输入。
- 左右修饰键需分别追踪，组合后不能清除仍按住的键状态。
- 透明色不等于透明桌面窗口；实际穿透、焦点和绿色存储行为必须测试。

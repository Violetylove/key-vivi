# KeyVivi 设计文档

更新日期：2026-10-05（Asia/Shanghai）。本文维护实现设计；需求、进度和验收见[项目规格](project_spec.md)，开发操作见[贡献规范](CONTRIBUTING.md)。

## 架构与职责

采用 Go、Win32 和 Go 位图渲染。入口 `cmd/keyvivi/main.go` 调用 `internal/app.Run`。

| 模块 | 职责 |
|---|---|
| `keyboard` | 物理键名、左右修饰键状态、完整组合与连按 |
| `display` | 输入行身份、队列、续期、到期、暂停和控制快捷键过滤 |
| `render` | 字体测量、键帽布局、位图与预乘 alpha 合成 |
| `platform` | 钩子、热键、消息循环、窗口、托盘、设置控件与屏幕几何 |
| `app` | 配置读写、会话装配、输入调度、动画场景与生命周期 |

`render` 不依赖其他内部模块，输出 `*image.RGBA`；`platform` 接收位图、坐标和通用设置描述，不依赖应用配置或主题。依赖版本以 [go.mod](../go.mod) 为准。

## 输入与线程

组合输入由按下/释放状态决定。左右修饰键独立追踪，组合完成后保留仍按住的键；只使用采集时间判断连按与显示停顿。

UI 主 goroutine 使用 `runtime.LockOSThread`，持有窗口、控制器、队列、动画、设置与托盘状态，运行 `GetMessage/TranslateMessage/DispatchMessage`。隐藏消息窗口使用顶层窗口，以接收显示器广播。

钩子线程有独立消息循环，只负责非阻塞投递事件。输入和控制通知投递后通过 `Loop.Wake()` 显式唤醒 UI，初始化缓冲在 UI 就绪后排空。控制通知优先处理。

缓冲溢出时记录丢失数量并唤醒 UI；恢复时清空状态、屏蔽仍按住的物理键，并丢弃恢复点之前的事件。停止钩子使用独立事件句柄，避免依赖已满的消息队列。

## 队列与动画

`Entry.ID` 标识完整输入，`GroupID` 标识所在行。行数容量包含退场行，超出容量时整行淘汰。当前行追加或计数更新会整体续期，其他行独立到期。

UI 将无裁剪的 `render.Layout` 测量回调注入 `Queue.Fits`，按实测宽度换行。数量不限制行长；单项超宽由渲染层缩小至 12 逻辑像素，仍超宽则按完整 Unicode 字符省略，逻辑文本不变。

第三次连按只合并当前行的本轮尾部两项，保留第一项身份与入场进度。换行后重新累计展示计数，不修改上一行。

`scene` 按输入 ID 缓存完整键帽图片，文本、计数、主题或几何改变时才重建。保持阶段复用帧，动画合成已有快照；画布逐帧清空并复用。

新键帽入场完成后获得完整停留时间；计数更新不能缩短期限。行切换插值纵坐标，抢占从当前坐标续接；移动中追加继承同行运动，横坐标不动画。新行经底部裁剪边界滑入，不向工作区外扩展窗口。

16ms Go `time.Ticker` 只投递合并的帧消息，UI 才推进状态。时钟代次屏蔽过期消息；无输入、提示和退场快照时停表，退出等待投递协程结束。

暂停立即清空队列、提示、动画快照并隐藏。恢复重置输入状态，跨暂停按住的键须先释放。

## 分层窗口与定位

字幕窗口使用：

```text
WS_POPUP
WS_EX_LAYERED | WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE |
WS_EX_TRANSPARENT | WS_EX_TOPMOST
```

Go 预乘 RGBA 转换为 top-down 32 位预乘 BGRA DIB，通过 `UpdateLayeredWindow` 提交；alpha 只预乘一次，使用 `AC_SRC_OVER`、`AC_SRC_ALPHA` 和常量 alpha 255。

`Apply(img, x, y)` 同时更新位图、尺寸和坐标，首次提交即定位且不激活；`Apply(nil, 0, 0)` 隐藏。DIB 替换前从 DC 换回原对象，检查关键 GDI 调用结果，失败不标记内部成功状态。

创建 HWND 前启用 DPI 感知。工作区、窗口和位图统一使用物理像素；逻辑尺寸按 `dpi/96` 缩放，字体以点数 `逻辑字号 × 72/96` 和实际 DPI 创建，避免重复缩放。

`PrimaryWorkArea` 取得主屏工作区，`RegionPosition` 计算稳定显示区域。区域高度由最大行数、行高和行间距确定，实际位图放在区域底部，行数改变不会移动区域锚点。边距按对应屏幕边缘向内换算，居中忽略水平值；定位越界时约束到工作区。DPI、工作区或显示器广播触发重新计算。

窄工作区先减少布局留白，再降低可读行宽；已有超宽行优先保留最新完整项，后续输入按新宽度换行。`OverlayPosition`、静态 `Bar/Fit` 用于诊断与 API 测试。

## 字体与配置

键帽使用逻辑像素内边距左右 8/上下 6、最小宽度 32、圆角 6、描边 1 和向下 2px 阴影；完整组合只绘制一个键帽，计数使用较小字号，空隙透明。

字体依次尝试 `Deng.ttf`、`msyh.ttc`、`simhei.ttf`、`simsun.ttc`，集合取首字体；失败回退内嵌 Go Regular。缺字方向键和提示使用英文降级。缓存一个解析字体与最多 16 个 face，锁覆盖测量、绘制和关闭。

配置位于 `os.Executable` 同目录，`config.go` 维护模型与校验，`settings.go` 映射控件和预览。尺寸为逻辑像素，时间为毫秒；产品默认值及范围见[规格](project_spec.md#配置)。

YAML 严格解码拒绝重复/未知字段、多文档、空值、别名与合并，文件上限 64KiB。先补默认值再校验；错误保留文件并使用默认配置。保存保留注释，同目录临时文件写入、同步并关闭后，以 `MoveFileEx(REPLACE_EXISTING|WRITE_THROUGH)` 替换，成功才更新文档和活动模型。

## 设置窗口

原生窗口独立显示任务栏项和 KV 图标，所有控件与回调由 UI 线程管理。草稿与活动配置分离，预览使用独立 `scene`，不写正式输入队列。

位置和主题下拉框保留原生列表与键盘导航，收起项通过子类回调绘制圆角、文本和箭头。按钮、列表项和开关使用 owner-draw，输入框保留原生编辑。消息参数保持 `uintptr`，仅在 `WM_DRAWITEM` 复制对应结构。

固定预览与底栏；视口和内容子窗口负责裁剪，滚动整体移动内容并重绘子控件。自行维护滚动位置，不设置 `WS_VSCROLL`；`IsDialogMessageW` 处理 Tab、回车和 Esc，焦点移入不可见项时滚入视口。DPI 重排保留草稿、滚动比例和焦点。

`ChooseColorW` 以设置窗口为 owner，在 UI 线程模态运行；确认更新草稿，取消或失败保留原值。自定义色只存内存。配置文件按钮通过 `ShellExecuteW` 打开文件关联，失败显示状态。

保存成功后重新装配主题、容量、时长与宽度回调，清除队列和动画，同步物理键状态，保留当前暂停状态。控件销毁时移除子类与路由，在 `WM_NCDESTROY` 释放字体；清理入口不随重开累积。

## 启动、托盘与清理

启动先检查实际令牌，低于 Medium 时在配置和钩子装配前退出，不自行提权。构建产物可能继承工作区 Low 标签，因此 `build.ps1` 仅将产物标为 Medium，保留目录安全设置。

初始化顺序为完整性检查、DPI、配置、消息窗口、字幕窗口、钩子、热键、托盘。托盘通过 `Shell_NotifyIconW` 管理，图标在内存中生成；`TaskbarCreated` 后重建。热键使用 `MOD_NOREPEAT`，控制按键和修饰键释放不进入字幕。

热键占用时提示使用托盘；托盘失败时保留 `Ctrl+Alt+Q` 退出兜底。所有控制入口失败时清理并结束，不能留下隐藏进程。

退出先禁止新投递并停表，再移除托盘、停止钩子/热键、销毁窗口和 GDI 资源。窗口及资源必须在创建线程释放；初始化失败逆序清理，不能在初始化回调中提前 `defer` 活跃资源。

诊断仅记录生命周期、数量、错误、尺寸和完整性级别，不输出按键内容或写日志文件。运行开关：`KEYVIVI_DEBUG` 输出平台诊断；`KEYVIVI_READY_HINT` 设置启动提示秒数（0–3600，默认 1.5，非法值回退默认，0 关闭）；`KEYVIVI_SELFTEST=1` 显式注入 F24 自检，默认不注入。测试开关见贡献规范。

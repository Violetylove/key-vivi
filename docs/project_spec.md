# KeyVivi 项目规格

更新日期：2026-10-07（Asia/Shanghai）。本文维护产品需求、里程碑、进度与验收；实现方式见[设计文档](architecture.md)。

## 范围

面向 Windows 10/11 x64 的录屏、演示和教学工具，目标为单 exe、免安装、无需管理员权限运行。v1.0 包含键盘可视化、托盘、动画、YAML 与设置窗口；可选风格、鼠标和多显示器功能属于 v2.0。

## 输入与显示

- 显示物理键名，覆盖字母、数字、符号、方向键、F1–F12 与常用特殊键；组合键完整显示为一个键帽。
- 修饰键按下时暂不显示，未参与组合则释放时显示；保持修饰键时可连续组合。左右修饰键独立追踪，组合顺序为 Ctrl、Alt、Shift、Win。
- 相同完整输入间隔小于 500ms 时累计；第一次显示一项，第二次保留两项，第三次合并为计数，长按自动重复也计数。不同输入或达到 500ms 重置，换行不改写历史计数。
- 连续输入向右追加，停顿达到 700ms 或行宽不足时换行。不限制每行元素数；默认最多 3 行，包含退场行，旧上新下，超出容量整行淘汰。
- 当前行输入整体续期，其他行独立到期。默认淡入 100ms、完整停留 1500ms、淡出 300ms、行移动 120ms；关闭动画后立即显示，到期直接隐藏。
- 独立半透明圆角键帽，组合不拆分，空隙透明，无整行衬底。无边框、标题栏和任务栏项，置顶、穿透且不抢焦点。
- 位置为左上、上中、右上、左下、下中、右下，默认左下；使用向内非负边距，上中/下中忽略水平值，切换位置不改数字。可见行数改变不移动区域锚点，DPI 或工作区变化后保持有效位置。

## 控制与设置

托盘提供暂停/继续、设置、关于、退出；`Ctrl+Alt+K` 切换暂停，控制快捷键不显示。暂停立即隐藏并清空待显示输入，恢复不补显暂停期间或跨暂停按住的键。热键占用、托盘失败必须提供明确提示与可用退出路径。

设置窗口按显示区域、外观与布局、行为与动画排列，每行一个设置项，说明使用“行”。预览与操作栏固定，内容滚动不显示系统滚动条；支持 Tab 导航、回车保存、Esc 取消与 DPI 重排。

Mocha/Latte 主题、六位置下拉和颜色色块提供实时草稿预览。颜色确认才更新，取消保留原值；设置主题不覆盖键帽颜色。保存立即应用并保持窗口打开；取消或关闭只丢弃未保存草稿，恢复默认需保存才生效。失败保留草稿、文件和活动配置。“打开配置文件”位于“恢复默认”旁，不显示配置路径。

## 配置

`keyvivi.yaml` 位于实际 exe 同目录，与工作目录无关。首次缺失时尝试生成带中文注释的默认文件；缺失字段补默认值，非法配置提示后使用默认值并保留原文件。目录不可写时仍能使用默认值，保存须明确报错。保存保留注释；手动编辑后重启加载，更新 exe 不覆盖配置。

| 类别 | 配置 | 默认值 / 范围 |
|---|---|---|
| 显示区域 | 位置、水平/垂直边距、最大行宽 | 左下；边距各 24（0–10000）；行宽 420（160–1200） |
| 外观与布局 | 设置主题、字号、文字/背景颜色 | Mocha（可选 Latte）；18（12–48）；`#FFFFFF` / `#14181F` |
| 外观与布局 | 背景不透明度、元素/行间距 | 88%（0–100%）；8 / 16（各 0–40） |
| 行为与动画 | 最多行数、换行停顿、完整停留 | 3（1–6）；700（100–5000）；1500（200–10000） |
| 行为与动画 | 动画、启动暂停 | 开启；关闭，启动暂停只影响下次运行 |

尺寸单位为逻辑像素，时间为毫秒，颜色为 `#RRGGBB`。文件与设置窗口共用默认值和校验。

## 绿色与隐私

运行仅为配置保存写入 exe 同目录 YAML 和临时文件；不记录或上传按键，不写日志、字体缓存或临时图标，不创建服务、自启动或注册表配置。退出后可删除 exe 与配置移除程序。

暂停只能阻止后续展示，不自动识别密码框，也不能删除已录入视频的字幕。退出必须释放钩子、热键、时钟、窗口、托盘与 GDI 资源。
